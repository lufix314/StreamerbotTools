Command Syntax

!command - Basic command (no arguments)

!command {type} - Command with required argument. Replace {type} with an actual input of the given type.

!command ?{type} - Command with optional argument. Can be omitted.

!command {"value" or type} - Argument with multiple options. Choose on of the given types (e.g. !command value).
